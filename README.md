# AscendingMonk
A repository to migrate and further develop the legacy project WhoKnowsLegacy, and to mantain the website.

# Running the code:
On a *NIX system, navigate to the root directory and run
```bash
DB_PATH="test-database-name.(sqlite|db)" go run ./cmd/main
```
