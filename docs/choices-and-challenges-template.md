# A template for entries in `choices-and-challenges.md`
The format of a choices and challenges entry is (as of 25/09/2026):
- H2 (##) with Date (DD/MM/YYYY) as text.
- Then comes a description of the choice (under H2 "Description of choice")
- Then a reason for the choice (under H2 "Reason for choice")
- Finally, describe how the decision was made - was it made through plenary discussion, individual discretion or something else? Use h2 with title "How was this decided?" 

# Example:
## 04/09/2026
## Description of choice
We've chosen Go as our programming language.
## Reason for choice
Go contains everything we expect we will need in its standard library
- a template engine
- an easy way to set up a server
- integration with many database providers.

## How was this decided?
Majority voting in the planning channel in our Teams team.
